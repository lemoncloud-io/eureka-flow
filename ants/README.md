# 🐜 Ants - 프로젝트 가이드 및 작업 관리 공간

이 디렉터리는 **Antigravity AI 어시스턴트**와 개발자가 협업하며 프로젝트에 대해 파악한 정보, 주요 태스크의 히스토리, 에디터의 아키텍처적 의사결정 등을 체계적으로 누적 보관하는 공간입니다.

## 📁 문서 리스트

- **[🗺️ 프로젝트 구조 및 아키텍처 가이드](./project_structure.md)**:
    - Eureka Flow의 모노레포 구조(Nx & Yarn Workspaces) 분석
    - 각 애플리케이션(`apps/*`) 및 라이브러리 패키지(`libs/*`)별 역할 상세 요약
    - 4대 Zustand Store를 통한 상태 관리 설계 분석
    - CI/CD 배포 워크플로우(S3 + CloudFront + GitHub Actions) 소개
- **[📋 'process' 피처 개발 가이드 및 구조 정리](./process_feature_guide.md)**:
    - `apps/web` 핵심 기능인 `process` 피처 도메인 분석
    - 7대 주요 페이지 및 32개 전용 UI 컴포넌트의 역할 정리
    - Zustand, React Query 연동 방식 및 모킹 데이터 레이어 흐름 요약
    - 원활한 기능 개발을 위한 단계별 추천 로드맵 제공

---

이곳에 생성되는 가이드 문서들은 프로젝트 소스 코드에 직접적인 수정을 가하지 않으며, 신규 개발자 온보딩 또는 대규모 기능 설계 시 빠른 문맥 파악을 돕는 보조 자산으로 상시 업데이트됩니다.
