무료로 시작하기 공개 플로우 둘러보기
1

시작하기

첫 워크플로우를 만드는 4단계

1

플로우 생성

무료로 시작하기를 클릭하면 빈 캔버스가 열립니다. 상단 제목을 클릭해 플로우 이름을 변경할 수 있으며, 저장 상태(저장 완료)가 실시간으로 표시됩니다.

2

노드 추가

왼쪽 사이드바의 ⊞ 블록 아이콘을 클릭하면 노드 라이브러리가 열립니다. 원하는 노드를 클릭하면 캔버스 중앙에 자동 추가됩니다. 검색창에서 노드 이름으로 빠르게 찾을 수 있습니다.

3

노드 연결

노드 오른쪽 포트(출력)에서 드래그해 다음 노드의 왼쪽 포트(입력)에 연결합니다. 포트 색상이 데이터 타입을 나타내며, 타입이 맞지 않으면 연결이 자동으로 거부됩니다.

4

실행

노드 우측 상단 ▷ 버튼으로 단독 실행하거나, 우측 속성 패널 하단 이후로 실행으로 해당 노드부터 끝까지 한 번에 실행합니다. 완료 시 COMPLETED 뱃지가 표시됩니다.

3

화면 구성

에디터 각 영역의 역할

상단 툴바 toolbar

플로우 이름 편집 / 저장 상태 표시. 오른쪽에 열기, 저장, 실행취소/재실행(↺↻), 실행(●), 메뉴(≡) 아이콘.

노드 라이브러리 sidebar

⊞ 블록 아이콘 클릭으로 열기/닫기. 입력·처리·출력 카테고리로 분류. 노드 이름 검색 지원.

중앙 캔버스 canvas

노드를 드래그하여 자유 배치. 빈 공간 드래그로 뷰 이동. 핀치/스크롤로 줌. 우측 하단 미니맵으로 전체 파악.

속성 패널 inspector

노드 클릭 시 오른쪽에 나타남. 설명·설정·입력·출력 섹션. 모델, 프롬프트, 파라미터 설정.

하단 줌 컨트롤 zoom

−/+ 줌 조절, 배율 표시(100%), 전체 화면 맞춤(⊡), 뷰 리셋(↺) 버튼.

노드 헤더 버튼 node

▷ 단독 실행 · ⋮ 옵션 메뉴 · ✕ 삭제. 실행 완료 시 COMPLETED 뱃지 표시.

예시 플로우

그대로 따라 만들어보세요

예시 1 · 텍스트 → AI 글쓰기 → 미리보기

→

👁️ 미리보기

가장 기본적인 패턴. 텍스트 입력 노드에 프롬프트를 작성하고, AI 텍스트 노드에서 모델과 시스템 프롬프트를 설정하면 결과가 미리보기에 렌더링됩니다.

예시 2 · 이미지 분석 → 구조화 데이터 추출
🖼️ 이미지 입력
→
🧠 AI 텍스트
→
🧩 스키마 추출기
→
🐛 디버그 로그

이미지를 AI로 분석하고 결과를 JSON 형태로 구조화해 확인하는 패턴. Vision 모델을 활용한 이미지 태깅·분류에 유용합니다.

예시 3 · 이미지 생성 파이프라인

→

→
🎨 AI 이미지
→

키워드를 템플릿으로 이미지 생성 최적 프롬프트 형식으로 변환한 뒤 AI로 이미지를 생성하는 패턴입니다.

5

유용한 팁

더 빠르게 워크플로우를 만드는 방법

노드별 실행으로 디버깅

전체 플로우를 돌리기 전에 노드별 ▷ 버튼으로 하나씩 실행하면 어느 단계에서 문제가 생기는지 바로 파악할 수 있습니다.

디버그 로그를 중간에 배치

복잡한 워크플로우에서는 처리 노드 뒤에 디버그 로그를 연결해두면 데이터가 어떻게 변환되는지 단계별로 확인할 수 있습니다.

AI 텍스트 노드 — 속성 패널 적극 활용

우측 속성 패널에서 모델(Gemini 2.5 Flash 등), 시스템 프롬프트, Temperature를 노드별로 개별 설정할 수 있습니다. PRO MODE 토글로 Top P, Top K 등 고급 파라미터도 조절 가능합니다.

공개 플로우에서 레퍼런스 찾기

에디터 상단 메뉴 또는 홈의 공개 플로우 둘러보기에서 다른 사용자의 워크플로우를 참고해 빠르게 시작하세요.
